The detection gap

By the time a leaf looks sick, the disease is already several cycles deep.

Late blight and other fast fungal infections can re-infect a whole polyhouse within 24–48 hours. Soil probes measure what's in the ground, not what the plant absorbed. Satellites and drones show canopy damage only after it's already visible — and the marketable window has usually closed by then.

PhytoPulse measures the plant's own biochemical signal directly from the leaf, so an alert can fire while the plant is still stressed but not yet damaged.

Architecture

Four layers, no gateway hardware.

Compute goes to the two places already sitting in the field: the sensor's own chip, and the phone in the farmer's pocket. No dedicated LoRaWAN gateway, no SIM card, no app-store install.

Sensing

Leaf-clip or scan-probe

A chemiresistive sensor reads methanol and terpene VOCs straight from the leaf surface.

Edge compute

ESP32 on-sensor chip

One commodity chip handles the ADC, BLE radio and humidity compensation.

On-phone

Progressive Web App

Pairs over Web Bluetooth in a browser tab; the triage model runs on-device.

Cloud (opt-in)

Signature library

An anonymised stress score can sync to a shared Odisha-calibrated VOC library.

Honest caveat: Web Bluetooth doesn't run on Safari/iOS today. Phase 1 goes Android-first, with an iOS bridge scoped for Phase 3.
Two form factors, one sensor chemistry

Start with a spot-check. Upgrade to continuous.

Both devices share the same VOC chemistry and the same on-device model, so a customer can move from occasional scans to unattended monitoring without switching platforms.
